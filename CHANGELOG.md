## Unreleased

- Receive contacts from WSJT-X, JTDX, and loggers that send ADIF over UDP. Turn on reception in the status page's **WSJT-X and JTDX setup** or **ADIF over UDP setup** card, where you can also choose a different port if another program is using it.
- On Windows, Field Day Commander Relay now opens its status page in a separate Microsoft Edge window without tabs. Opening the page again reuses that window.
- Run `relay-portable.exe` without installing. Contacts, settings, and logs are saved in `relay-data` beside the program. Move or back up both together. The connection token stays in the PC's Windows keychain, so connect with a new enrollment code on another PC or Windows account. The portable version doesn't offer start at sign-in.
- Install Field Day Commander Relay with `relay-setup.exe` on 64-bit Windows 10 or later, without administrator rights. Run the new installer to update and keep saved contacts and your server connection. Uninstall from Windows' Apps list. Collected contacts, settings, and the connection token stay on the computer.
- Run one relay per computer, across Windows accounts. Starting it again opens the running relay's status page, and the new copy stops. If another Windows account's relay is running on this PC, yours won't run because logger ports belong to the whole computer.
- On Windows, turn on **Start the relay when I sign in to Windows** in the status page's **Start at sign-in** card below the logger setup. The relay starts collecting contacts when you sign in, including after a reboot during an event, without anyone remembering to start it. If nobody signs in, it won't start. N1MM contacts still aren't received while the relay is closed.
- Pick an event station from the server's list in the connected server card. Log file contacts and other contacts without a station name use your pick. **Use this station for all contacts** also replaces station names from loggers. Leave it off when several stations share the relay. Changes apply to queued contacts, and contacts waiting for a missing station are retried right away. Contacts already on the server stay on their station. With manage-stations permission, choose **New station** from the list and enter a name. The server creates it when its first contact arrives. Disconnecting or connecting again clears the pick.
- First version of Field Day Commander Relay. Connect it to Field Day Commander with an enrollment code. Requires Windows 10 or later. Receive contacts from N3FJP, ADIF log files, or N1MM Logger+. For N3FJP, use TCP networking. File share mode won't work. A status page and tray icon show the relay's status.
- Sync contacts, corrections, and deletes in both directions between N3FJP and Field Day Commander. Values Field Day Commander doesn't store, such as a 5NN report, stay as you typed them in N3FJP.
- Choose client role to join your club's existing N3FJP network server. Edits and deletes made in N3FJP while the relay isn't connected won't reach Field Day Commander because N3FJP's log doesn't record those changes. New contacts logged during that time are picked up when the relay reconnects.
- Choose server role to have N3FJP PCs connect to the relay, like a local Field Day Commander. The relay holds the log and saves contacts to disk. Logging keeps working without internet, but closing the relay stops logging until it's running again because N3FJP clients don't keep their own log. Point each PC at the relay's computer in N3FJP's Settings > Network.
- In server role, N3FJP on the same computer can connect by default. Turn on **Let other PCs connect** for other PCs on your club's network. Anyone who can reach port 1000 can add, change, or delete contacts without a password. Never forward that port from the internet. Windows may ask you to allow the relay through its firewall. The status page can't confirm that permission. If port 1000 won't open, check whether N3FJP's own network server is running on the same computer. The relay keeps retrying.
- Watch ADIF log files on disk with or beside N3FJP, including WSJT-X's wsjtx_log.adi. Choose up to 16 files with **Add log file**. The relay keeps looking for files that don't exist yet. Choose **Don't use N3FJP** when this computer's contacts only come from log files, and the status page will stop looking for N3FJP.
- Send only log file contacts from the event's dates. Older contacts are counted under **Outside the event** and aren't sent. Connect to Field Day Commander once so the relay can learn those dates before reading any files. Contacts stay in the files meanwhile, so none are lost. After that, the relay can read them while offline. Contacts logged while the relay was closed are picked up when it starts.
- Send corrected names, reports, exchanges, and other details from log files to Field Day Commander. These contacts use the picked station on the server, or the relay's name if none is picked. This is one-way: the relay never changes the files, and changes on the server don't reach them. Deleting a contact from a file doesn't delete it on the server. Changing its call, time, band, or mode makes it look like a new contact, and the old one stays. Fix those on the server.
- Receive new contacts, edits, and deletes from N1MM Logger+. Turn on **Receive N1MM contacts** to listen on this computer, or also turn on **Let other PCs send contacts** for other PCs on your club's network. Contacts use the logging PC's N1MM station name. This is one-way: nothing goes back to N1MM. After the relay has been closed, use N1MM's Tools > Rebroadcast all Contest QSO's to other Apps to catch up without duplicates. Fix deletes missed while the relay was closed on the server.
- Fixed seemingly random replacements after the relay synced contacts logged elsewhere, including in Field Day Commander: a new contact from any logger could take an old contact's station and operator, and the old contact disappeared from the server log. New contacts are now added with their own station and operator. Contacts already replaced aren't repaired automatically, but their previous values are in the server's audit log.
